October 21, 2026. This matrix defines the bounded characterization accepted for
Phase 0. It does not require universal BG2EE parity. Original scripts, actual
equipped resources, synthetic defense effects and observable state are identified
separately. Known differences are reproducible defects for Phase 1.

The eight-case query matrix was declared in the existing equipped-defenses
tooling and side-effect specification before execution. Final unique-script AI
fixture manifests were recorded before either runtime observation. Raw evidence
and old failed combat-save attempts remain preserved. This is a characterization
batch with explicit failed predicates, not a campaign completion certificate.

Untested dual-wield/offhand combinations, wider launcher/ammo/enchantment rules,
stock spell casts and expiration/refresh semantics, exact original action memory,
queue completion, broad encounter/SCS behavior, hidden RNG and campaign coverage
remain Phase 1 validation work. They cannot inherit a pass from these cases.
The [backlog](../roadmap/phase1-backlog.md) orders predicate, observation,
persistence and UI work; engine changes require separate authorization.
