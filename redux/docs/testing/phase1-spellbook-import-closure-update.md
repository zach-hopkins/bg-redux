# Spellbook helper source-freeze update

Source-only follow-up to the ordinary information and persistent confirmation helpers. The focused heading controller fixture now supplies an explicit information `Update=False` / `Reset` no-op stub: its assertions cover heading lifecycle/count plumbing only. Real information behavior remains in the separate actual-helper tests and pending native journeys; the stub cannot establish information assembly success.

The menu, hotkey, spellbook operation, Erase, cell recruitment, Minsc recruitment, Jaheira dialogue and spell-cast adapters now explicitly enumerate the new information/confirmation helpers, heading helper, GUIOPT/GUIOPTControls and persistent `defaults.ini`, together with the relevant existing Python GUI dependencies. This captures the new direct import paths without relying on an engine inventory's path/hash entries alone. Existing source-root, exact-set and current/frozen hash checks remain intact. The Erase table provenance retains root's corrected `core/TableMgr.h` / `plugins/2DAImporter/2DAImporter.cpp` paths.

Actual menu `freeze_source_inputs` and the journey build `shared.frozen_copy` loops copy these files into hash-addressed private receipt/source paths; journey run drivers copy the build's frozen closure again. Hotkey previously recorded source hashes without retaining their bytes. It now uses the menu's actual source freezer, stores `frozen_sources` in preparation/results, and includes frozen-byte equality in final pass acceptance alongside its existing current-input checks. This is a new receipt requirement, not retroactive proof for prior hotkey runs.

Two new resource-free tests execute all eight actual closure-builder functions with a fake source root and require the new imports/defaults. They exercise the actual freezer's missing-file rejection, retained source bytes, and independent current/frozen corruption detection. They do not launch an adapter, compiler, native process or game. Test source is **unexecuted by this worker**; the coordinator owns execution and resulting receipts.

Historical frozen drivers, build/run receipts and result verdicts are untouched. Fresh builds/runs must use the expanded closure; old closures fail current exact-set guards rather than being silently admitted. No GUIMG/GUIPR, production helper, source policy, engine binary or licensed asset is edited by this follow-up.
