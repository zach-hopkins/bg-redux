# Ordinary spellbook information journey

This is an unexecuted external diagnostic. It changes no engine, GUI controller,
spell resource or saved input. Coordinator tests, compilation, native execution
and screenshot review are required before any acceptance claim.

The immutable four-party Minsc parent is the same exact result/manifest/GAM/SAV
chain used by the operation journey. New host, startup, runtime, validator and
driver sources receive separate frozen closures and private profiles. Current
and frozen source bytes, candidate source/binaries/build support, compiler,
compiled helper derivation, all resource providers, Phase0 protected inputs,
private GamePath wrapper and every copied/frozen save remain guarded before and
after execution, including failures. Old operation/Erase receipts are untouched.

The runtime enumerates natural known counts after ordinary load and four idle
samples, while the independent validator derives the required plan from native
ready-state pages. It visits every naturally populated wizard and Jaheira priest
level, dispatches each real next-page button, and records every visible original
index/resref/localized name in the seven-row pool. Each page's first name is
selected and deselected through registered callbacks; both must conserve all
collected gameplay state. No natural list is expanded. `natural_over24` reports
whether this input actually supplies such a list; synthetic 31-entry tests do not
establish native coverage above 24.

At the fixed SPWI213/SPPR113 levels it switches away and back through real tabs,
then changes the open book's actor using ordinary portrait callbacks: fighter
leader for wizard, Imoen for priest. These read-only books must display complete
localized default help and a disabled actual window, with no selected identity.
Returning to the eligible caster must restore an enabled ordinary book with
fresh page/selection state. This route does not force a disabled toolbar opener
or a disabled action. The existing production help guard may fail this check;
that failure is retained, not treated as an accepted ineligible-book policy.

The selected target description binds the actual SPL description strref, frozen
TLK bytes and actual queried full text. The established strict PRO_HISHER token
resolver binds the exact gender table/provider and protagonist sex/mirror. Other
unrecognized description tokens fail explicitly rather than being stripped or
generically substituted. Actual information-scroll arrow callbacks must change
the captured text viewport and return it exactly, while full text and gameplay
state remain unchanged. A description that does not visibly overflow cannot
silently establish scroll coverage: it fails that bounded expectation and needs
a documented natural target adjustment, not an invented pixel oracle.

The mutation slice requires the observed confirmation option to be zero. It
removes the pinned charged prepared target through its existing callback, uses
the selected separate Memorize action to append exactly that resref as depleted,
checks the capacity-disabled separate action, and invokes the enabled icon
shortcut at full capacity to prove no mutation. It then removes the actual
depleted copy and uses the icon shortcut with free capacity. All intermediate
ordered resref/flag deltas, known entries, slots and other world surfaces are
checked. The final declared change is one original charged target becoming a
depleted copy, in each book, as in the existing operation contract. No rest,
cast, grant, cheat, option setter or production callback replacement is used.

Actual registered callbacks and their dictionary/value handling are distinct
from OS pointer hit testing. An independent route map rejects a mutating icon
substituted for a name selection or separate action. Normal GUISAVE callbacks
produce a uniquely named save; independent GAM/CRE/SAV decoding and a second
owned process verify the frozen save chain, exact known order/ready flags and
reload without further mutations. The optional existing four-name presentation
control remains explicit and separately provider/hash bound; it supplies no
original-game parity claim.

Ten focused test methods are supplied, including execution of the actual runtime
plan against an independently declared 31-entry inventory, missing/duplicate/
unbounded pages, selection/reset identity, wrong callback routes, hidden world
mutations and stale/incomplete/forced terminal claims. They were not executed by
this worker. The prior page-contract tests independently reject old layout
versions, missing names/help and incorrect visible controls.

The last control identifier must equal `spellbook_presentation_control.CONTROL`;
the driver rejects any other identifier. Compile timeout is at most 300 seconds,
owned operate/reload bounds are 900/780 seconds, native timer bounds are
2200/1800 callbacks, and the natural plan is capped at 650 steps and 256 known
entries per actor. These are limits, not measured performance claims. This
journey runs at 1024×768; the separate broad menu journey retains both required
resolutions. Per-label face/color/metrics, complete spontaneous book fidelity,
full-campaign behavior, RNG noninterference, original operation parity and OS
pointer input remain outside this diagnostic's claims.
